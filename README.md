# javascript-calculator-precourse

## 기능

    1. 문자열 입력을 요구하는 기능
    2. 유효한(기본, 커스텀) 구분자를 기준으로 숫자를 추출하고 더하는 기능
        쉼표(,)와 콜론(:)은 기본 구분자로, //와 \n 사이에 위치하는 문자는 커스텀 구분자로 지정
        2-1) 기본 구분자 구현
        2-2) 커스텀 구분자 적용 구현
    3. 예외 처리
    
## 예외처리
    1. 숫자와 구분자 이외의 문자
    2. 유효하지 않은 구분자 사용
    3. 소수점 사용
